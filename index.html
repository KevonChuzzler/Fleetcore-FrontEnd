How to Create a Google Maps API Key

Fast 4-step setup in Google Cloud Console

1
Go to Google Cloud Console

Visit console.cloud.google.com and sign in with your Google Account. If needed, create or select a project (e.g. "Fleet Management").

2
Enable "Maps JavaScript API"

In the search bar at top or via APIs & Services > Library, search for Maps JavaScript API and click Enable.

3
Create an API Key

Navigate to APIs & Services > Credentials → Click + CREATE CREDENTIALS → Select API key. Your key (starting with AIzaSy...) will be generated instantly.

4
(Recommended) Restrict the Key

Under "API restrictions", select Restrict key and check only Maps JavaScript API. Google provides $200 free credit monthly (approx 28,500 free map loads every month).
